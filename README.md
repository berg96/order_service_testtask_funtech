# Order Service

## Описание проекта

Сервис управления заказами на FastAPI с поддержкой:

* JWT-аутентификации (OAuth2 Password Flow)
* Фоновой обработки задач через Celery
* Очереди сообщений Kafka для публикации событий
* Кеширования заказов через Redis
* Полной документации API через SwaggerUI

Сервис позволяет создавать заказы, обновлять их статус, получать список заказов пользователя, а также обрабатывать их в фоне.

Документация API доступна по адресу [http://localhost/docs](http://localhost/docs)

---

## Реализованные эндпоинты

| Метод | Путь                        | Описание                                    |
|-------|-----------------------------|---------------------------------------------|
| POST  | `/register/`                | Регистрация пользователя                    |
| POST  | `/token/`                   | Получение JWT-токена (OAuth2)               |
| POST  | `/orders/`                  | Создание заказа (только авторизованные)     |
| GET   | `/orders/{order_id}/`       | Получение заказа (сначала из Redis)         |
| PATCH | `/orders/{order_id}/`       | Обновление статуса заказа                   |
| GET   | `/orders/user/{user_id}/`   | Получение всех заказов пользователя         |

---

## Очереди сообщений и фоновые задачи

* При создании заказа сервис публикует событие `new_order` в Kafka
* Отдельный faststream service с имеющимся consumer, который подписан на `new_order` и вызывает фоновую задачу Celery `process_order`
* Celery выполняет обработку заказа (`time.sleep(2)` и `print(f"Order {order_id} processed")`)

---

## Кеширование

* Заказы кешируются в Redis с TTL = 5 минут
* При повторном запросе заказ отдаётся из кеша
* При обновлении заказа кеш обновляется
* При запросе и валидном токене пользователя данные о нем кешируются в Redis c TTL = 1 минута

## Как запустить проект

1. Клонировать репозиторий:
```
git clone https://github.com/berg96/order_service_testtask_funtech
```
2. Перейти в папку проекта:
```
cd order_service_testtask_funtech
```
3. Создать файл .env на основе примера .env_example и заполнить переменные окружения:

4. Запустить все сервисы через Docker Compose:
```
docker compose up -d
```

Документация API при запущенных контейнерах доступна по следующему адресу:
[http://localhost/docs](http://localhost/docs)
